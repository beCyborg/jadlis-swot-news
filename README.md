# SWOT News — ежедневный персональный SWOT мировых новостей

Плагин Claude Code: берёт свежий батч [Kagi News](https://news.kagi.com) (публичный API, ключ не нужен) и пишет компактный дельта-выпуск — что из случившегося касается лично тебя и что с этим делать.

## Зачем

Лента даёт эмоции, а не позицию: важная новость и твоя новость — разные новости. Пока в событии нет тебя, оно остаётся чужой важностью, а к вечеру от него не остаётся ни решения, ни следа.

Плагин ставит между лентой и тобой отбор и разбор (тег `swot-news--v1.0.1`):

- Берёт только выбранные на онбординге направления из живого каталога Kagi (в скилле ориентир ~165 направлений; валидный выбор — 12–60, комфортный — 25–40).
- Раскладывает их по 1–4 кластерам и запускает по аналитику на кластер плюс обогатителя — параллельно, одним сообщением.
- Каждая запись получает две оценки — сила удара и вероятность — и попадает в выпуск, только если что-то меняет для тебя.
- Пишет **дельту**, а не пересказ: новое, эскалация, затухание, без изменений — по отношению к вчерашнему выпуску.
- Устойчивые темы становятся карточками базы и живут своей историей; без упоминаний ≥ 14 дней тема помечается затухающей, ≥ 30 — уходит в архив.

## Как поставить

Вставь этот блок агенту в Claude Code, открытом в рабочей папке:

```text
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
2. Bash: claude plugin install swot-news@jadlis
3. Скажи мне одной строкой: «Отправь /reload-plugins, потом напиши: /swot-news:setup»
Ничего не читай, не создавай и не ставь помимо этого.
```

Ручной путь — те же команды. Основной канал — хаб `jadlis`, в нём плагин идёт подшагом 6.3 маршрута передачи:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
claude plugin install swot-news@jadlis
```

Отдельно от хаба — свой маркетплейс репозитория:

```bash
claude plugin marketplace add https://github.com/beCyborg/swot-news-plugin.git
claude plugin install swot-news@swot-news-plugin
```

Полный HTTPS-URL обязателен: короткая форма `owner/repo` разворачивается в SSH-адрес, а SSH-ключа у нового пользователя обычно нет. Обновление у сторонних маркетплейсов по умолчанию не автоматическое: `claude plugin update swot-news@jadlis` (или `@swot-news-plugin`), либо включить авто-обновление один раз в `/plugin` → Marketplaces.

Подробная установка с решением проблем — **[docs/УСТАНОВКА.md](docs/УСТАНОВКА.md)**.

## Как пользоваться

Три типовых сценария:

1. **Первый запуск** — `/swot-news:setup`. Разбор папки, интервью о профиле, проход по направлениям Kagi, раскладка по кластерам, создание структуры. Без конфига `daily` печатает одну строку и ничего не создаёт.
2. **Ежедневный выпуск** — `/swot-news:daily`. Сбор → анализ → выпуск → дайджест в чат. Вопросов не задаёт, поэтому его можно вешать на расписание; `--force` перезаписывает сегодняшний выпуск.
3. **Поправить настройку** — `/swot-news:setup --recheck` (пересобрать категории, каталог Kagi меняется) или `/swot-news:setup --profile` (только профиль, категории не трогает).

Все поля конфига — **[docs/НАСТРОЙКА.md](docs/НАСТРОЙКА.md)**.

## Границы и стоимость

Что нужно и чего плагин не делает:

- **Нужен контекст о тебе.** Отбор идёт по `Контекст.md` — профиль, интересы, приоритеты. Пустой контекст превращает выпуск в обычную ленту.
- **Требования:** Claude Code (CLI или десктоп), Python 3.9+ (только стандартная библиотека, ставить нечего), интернет к `news.kagi.com`. Ключей и платных подписок плагин не требует.
- **Необязательное:** Brave Search MCP — если подключён, ежедневное обогащение тем идёт через него, иначе через встроенный веб-поиск или не идёт вовсе. Obsidian плагин определяет сам: с ним wikilinks, callouts и `.base`-дашборд, без него — обычный Markdown.
- **Пустой день остаётся пустым.** Батч не новее последнего выпуска — заметка не создаётся, в чат уходит одна строка. Мусорных файлов от неудачного прогона не остаётся.
- **Кластер-файлы весят мегабайты** и в основной контекст не читаются никогда — аналитики получают пути, а не содержимое.
